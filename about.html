About This Project

PowerWise AI is a responsive web application for electricity consumption prediction and waste minimization. It uses client-side machine learning to train directly in the browser from a user-supplied dataset.

Built for flexibility

No backend required. Your data stays in your browser while the AI model is trained and stored locally.

Predictive insights

Forecast consumption, detect high wastage, and receive intelligent suggestions for more efficient usage.

Open dataset support

Upload CSV files from outside sources and experiment with real energy telemetry.
